# Wrabble brand assets

| File | Use |
|---|---|
| `wrabble-lockup.png` | Mark + wordmark, transparent. Headers, README, slides. |
| `wrabble-lockup-paper.png` | Same on the app's paper background. |
| `wrabble-mark.png` | Book stack alone, transparent. |
| `wrabble-mark.svg` | Vector mark. Scales to any size. |
| `wrabble-icon.svg` / `.png` | App icon / avatar. Simplified so it survives at 16px. |
| `icon-*.png` | Icon at 1024, 512, 256, 180 (iOS), 64, 32. |

Wordmark is **Fraunces 700**. The mark is line art in `#40291c` over the app palette.

Colours: ink `#40291c` · terracotta `#c9622e` · paper `#fbf1de` ·
book warm `#f0c9a0` · cool `#a9cddb` · pink `#f0b8c4` · leaf `#a8cba4`

The lockup PNGs are rendered with the real webfont, so there is no text-as-SVG
version — regenerate from `web/js/art.js` if the mark ever changes.
